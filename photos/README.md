# Photo Instructions

Place your 6 wedding photos in this folder.

## Recommended names:
- photo1.jpg — Main couple photo (for the large first tile)
- photo2.jpg
- photo3.jpg
- photo4.jpg
- photo5.jpg
- photo6.jpg — Panoramic shot (for the wide bottom tile)

## Image specs:
- Format: JPG or PNG
- Size: 1200-2000px wide
- Keep file sizes under 500KB each for fast loading

## How they'll be used:
Each photo replaces a placeholder in index.html's gallery section.

See the main README.md in the parent folder for detailed instructions.
